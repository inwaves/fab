# KB Source Map

Fab is larger than the local `inwaves/kb` repo, but that repo is a useful design
reference because it shows one concrete knowledge substrate: papers, articles,
research directions, media, own work, code, tags, and human-only judgment fields.

Use this map when grounding Fab design in nearby notes.

## Strategic Notes

- `kb/research/alignment-via-ai-assistance.md`
  - Frames the brittle automated-alignment-researcher thesis.
  - Useful takeaway: the research production system itself becomes a safety
    object once AI assistance dominates alignment work.
- `kb/research/mitigations-to-automated-alignment/README.md`
  - Frames the bridge problem: how current mitigations might carry us to useful
    AI-assisted alignment work.
  - Useful takeaway: AI-assisted research epistemics is underdeveloped.
- `kb/research/alignment-factory/README.md`
  - Historical source for this project.
  - Treat as background, not the current design source of truth.

## Adjacent External Efforts

- `kb/papers/the-last-human-written-paper-agent-native-research-artifacts.md`
  - Agent-native artefacts: structured logic, executable code/specs,
    exploration traces, and grounded evidence.
  - Useful takeaway: prose papers are too lossy for agent continuation.
- `kb/articles/the-new-age-of-research.md`
  - Paradigma/Flywheel's broader autonomous-science framing.
  - Useful takeaway: research lineage and branching are naturally graph-shaped,
    but Fab does not need the graph to be the atomic unit.

## Design Rule From KB

The KB's `engaged` and `insightful` fields are human-only. That is the important
analogy for Fab: agents can propose, cite, test, package, and connect, but human
judgment decides what changes durable understanding.
