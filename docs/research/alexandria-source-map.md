# Alexandria Source Map

Alexandria is the public substrate Fab assumes for the MVP. It is useful as one
concrete research substrate: papers, articles, research directions, media, own
work, code, and human judgment fields.

Use this map when grounding Fab design in nearby notes. Treat every path here as
an example of a possible Alexandria path, not as a permanent Fab path convention.

## Strategic Notes

- `research/alignment-via-ai-assistance.md`
  - Frames the brittle automated-alignment-researcher thesis.
  - Useful takeaway: the research production system itself becomes a safety
    object once AI assistance dominates alignment work.
- `research/mitigations-to-automated-alignment/README.md`
  - Frames the bridge problem: how current mitigations might carry us to useful
    AI-assisted alignment work.
  - Useful takeaway: AI-assisted research epistemics is underdeveloped.
- `research/alignment-factory/README.md`
  - Historical source for this project.
  - Treat as background, not the current design source of truth.

## Design Rule From Alexandria

Alexandria can contain human-only fields. That is the important analogy for Fab:
agents can propose, cite, test, package, and connect, but human judgment decides
what changes durable understanding.
