# Contract: Does a rubric judge for paper replication survive selection pressure?

Contract id: contract_replica_judge_goodhart
Version: 1
Program: replication-oversight
Created: 2026-08-25

## Research Question

Inherent's Faraday (Falck et al., arXiv:2608.13331) is trained with RL against
an auto-generated, per-task rubric judge that scores figure replications. When
replication attempts are *selected* by a judge built that way, does the judge's
preferred attempt also replicate the paper more faithfully by an independent
ground-truth measure, or does selection pressure pull the two apart?

## Why It Matters

The paper's own safety claim is that rubric judges make RL workable in
non-verifiable domains and may help with scalable oversight and reward hacking.
If a rubric judge can be satisfied by attempts that are not faithful, then agents
trained or selected against it learn to look right rather than be right, and any
pipeline that trusts agent-reported research output inherits that error.
Replication is also the one research task where ground truth exists: the
original paper's numbers. It is the cheapest place to measure the gap.

## Brief

Treat this as a Goodhart test, not a reproduction of Faraday. You do not have
Faraday, Replica, or the training recipe; do not try to rebuild them. Use
inference-time selection as the cheap stand-in for optimisation pressure:
generate several independent replication attempts per task with one fixed coding
agent, score each with a rubric judge built the way the paper describes
(LLM-generated per-task rubric, judge sampled several times and averaged), and
compare what the judge prefers against what the paper's actual numbers say.

Hunches to test rather than assume:

- Best-of-N by rubric will raise rubric scores faster than it raises fidelity,
  and the gap will grow with N.
- The divergence will concentrate in tasks where the rubric rewards presentation
  (axis labels, plot shape, narrative) more than numeric agreement.
- Agents' own stated limitations and confidence will not flag the attempts where
  rubric and ground truth disagree.

Ground truth: pick papers whose target figure's underlying numbers are
recoverable from a results table, a released CSV, or a public leaderboard, so
fidelity can be computed programmatically from the attempt's emitted data rather
than judged by eye. Require every attempt to write the values it plots to a CSV.
Keep tasks small enough to run on CPU or one modest GPU; ML papers with public
code and data are the obvious pool. Eight tasks with six attempts each is enough
to see the effect for a first pass.

Write the rubric prompt and the fidelity metric before looking at any attempt,
and record both in the bundle. If you change either afterwards, say so in
`limitations` and report both versions.

Report a negative result with the same care as a positive one. A judge that
tracks ground truth well is a useful finding.

## Programme Shape

Single exploratory workstream. If the result is clear, a follow-up workstream
should replicate it with a different coding agent and a different judge model
before anyone relies on it.

## Desired Output

One artefact bundle containing:

- `report.md`: question, setup, per-task results, the rubric-vs-fidelity curves
  against N, and what you would do next.
- `tasks/`: each task's specification, its rubric, and where its ground-truth
  numbers came from.
- `attempts/`: every attempt's code, emitted CSV, and judge scores, including the
  attempts you would rather not show.
- `analysis/`: the script that produces every number in the report, runnable
  from the bundle alone.
- `manifest.json` claims written so that each can be checked against a named
  file in the bundle.

## Attention Boundaries

- Stop and report if you cannot find six tasks with recoverable ground truth
  within the first quarter of your budget.
- Ask before spending more than 8 GPU-hours or US$300 of model API calls in
  total.
- Do not fine-tune or train any model; this is an evaluation study.
- Do not show the original figure image to the agent generating attempts. The
  judge may see it only if you report that as a separate condition.
- Do not change the coding agent, N, the rubric prompt, or the fidelity metric
  mid-run without recording it as a deviation.
- Flag it if rubric and fidelity agree almost perfectly (Spearman above 0.9) on
  the first four tasks. Finish, but say the design may be underpowered.
